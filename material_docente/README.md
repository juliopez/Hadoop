# Material Docente

Este directorio reúne los recursos académicos utilizados en el curso **Big Data**, complementando la infraestructura tecnológica disponible en este repositorio.

Mientras la raíz del proyecto contiene los componentes necesarios para desplegar un entorno Big Data mediante Docker Compose (Hadoop, Spark, Hive, Kafka y NiFi), esta sección concentra el material utilizado en el proceso de enseñanza y aprendizaje.

---

# Contenido

## Libro del curso

El libro constituye el recurso principal del curso y desarrolla progresivamente los fundamentos, arquitecturas y tecnologías del ecosistema Big Data.

```
Big Data:
Fundamentos, Arquitecturas y Procesamiento Distribuido
```

El texto está organizado en cinco partes:

| Parte | Contenido |
|--------|-----------|
| I | Fundamentos del Big Data |
| II | Ecosistema Hadoop |
| III | Procesamiento Distribuido |
| IV | Procesamiento de Eventos |
| V | Analítica en Tiempo Real |

El libro puede consultarse en formato PDF o mediante los archivos Markdown utilizados durante su edición.

```
material-docente/
└── libro/
```

---

## Presentaciones

Las presentaciones corresponden al material utilizado durante las clases del curso y se encuentran organizadas cronológicamente por semana.

Cada carpeta contiene la versión editable en PowerPoint y una versión PDF para consulta.

```
material-docente/
└── presentaciones/

    ├── semana-02/
    ├── semana-03/
    ├── ...
    └── semana-15/
```

## Laboratorios

Los laboratorios permiten aplicar los contenidos desarrollados durante el curso mediante ejercicios prácticos sobre las tecnologías revisadas.

Entre las actividades se incluyen:

- Hadoop
- HDFS
- Hive
- Apache Spark
- PySpark
- Apache Kafka
- Structured Streaming
- Integración de tecnologías Big Data

```
material-docente/
└── laboratorios/
```

# Objetivo

El propósito de este material es proporcionar un conjunto integrado de recursos para facilitar el aprendizaje de las principales tecnologías utilizadas actualmente en plataformas Big Data, combinando fundamentos teóricos, laboratorios prácticos, simulaciones interactivas y casos de estudio aplicados.

Todos los recursos han sido diseñados para utilizarse conjuntamente con la infraestructura tecnológica disponible en este repositorio.
