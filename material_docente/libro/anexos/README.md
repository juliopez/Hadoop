# Anexos

Este directorio reúne material técnico complementario al contenido principal del libro.

Los anexos incluyen comandos, configuraciones, procedimientos y recursos de consulta rápida que apoyan el desarrollo de los laboratorios y casos de estudio, evitando interrumpir la continuidad del texto principal.

## Contenido

| Anexo | Descripción |

| Anexo B | Comandos básicos de HIVE |

| Anexo E | Comandos básicos de Apache Kafka |
| Anexo F | Comandos básicos de Apache Spark Structured Streaming |

## Objetivo

Los anexos constituyen material de referencia para el estudiante durante el desarrollo de las actividades prácticas del curso. Su consulta es complementaria al contenido desarrollado en cada capítulo y permite acceder rápidamente a comandos y configuraciones de uso frecuente.
