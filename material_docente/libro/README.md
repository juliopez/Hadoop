---

## Descripción

Este libro presenta una introducción progresiva a los principales conceptos, arquitecturas y tecnologías utilizadas actualmente en plataformas Big Data.

A diferencia de muchos textos centrados únicamente en aspectos teóricos o exclusivamente prácticos, esta obra integra fundamentos conceptuales, ejemplos, casos de estudio y actividades de laboratorio, permitiendo al estudiante comprender el funcionamiento completo de una arquitectura Big Data moderna.

El recorrido del libro comienza con los fundamentos del Big Data y culmina con el desarrollo de soluciones de procesamiento de eventos en tiempo real mediante Apache Spark Structured Streaming.

# Público objetivo

Esta obra está dirigida principalmente a:

- estudiantes de Ingeniería Informática;
- estudiantes de Ciencia de Datos;
- estudiantes de Ingeniería en Computación;
- profesionales que desean iniciarse en tecnologías Big Data;
- docentes que imparten asignaturas relacionadas con procesamiento distribuido y analítica de datos.

No se requieren conocimientos previos sobre Hadoop o Apache Spark, aunque es recomendable contar con nociones básicas de programación y bases de datos.

---

# Objetivos de aprendizaje

Al finalizar el estudio del libro, el lector será capaz de:

- comprender los fundamentos del Big Data;
- identificar las principales arquitecturas utilizadas actualmente;
- implementar soluciones utilizando Apache Hadoop;
- procesar grandes volúmenes de datos mediante Apache Spark;
- desarrollar aplicaciones distribuidas con PySpark;
- capturar eventos utilizando Apache Kafka;
- construir aplicaciones de analítica en tiempo real mediante Apache Spark Structured Streaming;
- integrar las tecnologías estudiadas dentro de una arquitectura Big Data moderna.
