# Capítulos

Este directorio contiene los archivos fuente del libro **Big Data: Fundamentos, Arquitecturas y Procesamiento Distribuido**.

Cada capítulo ha sido desarrollado en formato **Markdown**, facilitando su edición, revisión, control de versiones y posterior publicación en distintos formatos (PDF, HTML, EPUB, entre otros).

# Estructura editorial

Todos los capítulos siguen una estructura homogénea con fines didácticos, la cual considera, según corresponda:

- Introducción.
- Desarrollo conceptual.
- Arquitecturas y componentes.
- Ejemplos prácticos.
- Figuras e ilustraciones.
- Caso de estudio.
- Resumen.
- Actividades.
- Laboratorio.
- Lecturas recomendadas.
- Referencias bibliográficas.

Cuando la temática lo requiere, cada capítulo incorpora además un enlace a un anexo con comandos, configuraciones o recursos técnicos complementarios.

---

# Convenciones

Durante el desarrollo del libro se utilizan las siguientes convenciones:

- Los capítulos están escritos en lenguaje Markdown.
- Las figuras se almacenan en el directorio `../imagenes/`.
- Las imágenes se insertan mediante bloques HTML para asegurar una presentación uniforme en los distintos formatos de publicación.
- Los anexos técnicos se almacenan en el directorio `../anexos/`.
- Los ejemplos de código utilizan bloques Markdown con resaltado de sintaxis.

# Estado del contenido

Los capítulos se encuentran organizados de acuerdo con la siguiente estructura general:

- **Parte I:** Fundamentos del Big Data.
- **Parte II:** Ecosistema Hadoop.
- **Parte III:** Procesamiento Distribuido.
- **Parte IV:** Procesamiento de Eventos.
- **Parte V:** Analítica en Tiempo Real.

Cada capítulo puede evolucionar mediante nuevas revisiones, incorporando mejoras editoriales, ejemplos, figuras y casos de estudio, manteniendo siempre la coherencia con el resto de la obra.
