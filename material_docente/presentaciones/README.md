# Presentaciones

Este directorio contiene las presentaciones utilizadas durante el desarrollo del curso **Big Data**.

Las presentaciones acompañan el contenido del libro **Big Data: Fundamentos, Arquitecturas y Procesamiento Distribuido**, proporcionando un apoyo visual para las clases teóricas, demostraciones prácticas y actividades desarrolladas durante el semestre.

---

# Objetivos

Las presentaciones tienen como propósito:

- introducir los conceptos fundamentales de cada unidad;
- explicar arquitecturas y componentes mediante diagramas;
- apoyar demostraciones realizadas durante la clase;
- complementar el contenido desarrollado en el libro;
- servir como material de repaso para los estudiantes.

---

# Contenido de las presentaciones

En general, cada presentación considera:

- objetivos de aprendizaje;
- contenidos teóricos;
- diagramas e ilustraciones;
- ejemplos prácticos;
- demostraciones paso a paso;
- ejercicios de discusión;
- actividades de cierre.
